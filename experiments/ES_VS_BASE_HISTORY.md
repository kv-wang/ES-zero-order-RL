# vanilla ES 在历史实验中是否胜过未训练 base (2026-08-14,零 GPU)

**结论:在所有存在未训练基线的场合中,vanilla/full-param ES 只在一处胜过 base——
countdown(base 0.08 → 0.45)。数学任务上跨三个基座、跨七月与八月、跨 `-Instruct` 与
非 Instruct,一次都没有胜过。这与 split-half ρ 完全吻合:countdown 的 ρ=0.51,
数学任务的 ρ 中位数精确为 0。**

## 问题

七月的实验,以及八月 `-Instruct` 那一轮里,vanilla ES 有没有胜过 base model?

## 方法与一个结构性发现

先查每个场合**是否存在**未训练基线的评测产物,再取值比较。

**七月四个 try 中,只有 `2026-07-24` 的 track_b 做过基线评测。**
`2026-07-18` / `2026-07-21` / `2026-07-23` 三个 try **一处基线评测都没有**
(只有 `theta_step0.pt` 权重快照,不是评测结果)。

这意味着那三个 try 里的全部 vanilla ES 结果,**在当时根本无法与 base 比较**——
它们只能相互比较。八月新增 `eval_base.py` 时注释写的"补齐此前缺失的未训练基线",
指的正是这个缺口。这本身是一个此前未被记录的方法学空洞。

基线产物共三份,全部在 `track_b/results/`:
`base/base_1.5B_instruct.json`、`exp3b_math/base_3b.json`、`exp3b_gsm8k/base_3b.json`。

## 与 ρ 的对应关系

| regime | base 起点 | split-half ρ | ES 是否胜过 base |
|---|---:|---:|---|
| countdown(07-30) | 0.08 | **0.51** | **是,+0.37** |
| MATH,`-Instruct` | 0.6452 | 0.000 | 否 |
| MATH,基座版 | 0.3594 | **0.000** | 否 |

**ES 不是"在某些模型上有效",而是"在奖励信号可分辨时有效"。**
countdown 的奖励天然带梯度(算式与目标的接近程度),数学任务在 B=8 的二元奖励下
只有约 3 个可分辨档位(上限 9)。换模型不改变这一点——基座版把 base 起点从 0.645 降到
0.359,ρ 仍然精确为 0。

## 需要一起说的限制

**七月的绝对数值不可用。** 全部受 `\boxed{}` 抽取器嵌套花括号缺陷影响
(见表中 minerva 抽取率 0.55、olympiad 0.72)。base 与 ES 同受影响,**配对方向仍成立**,
但差值大小不可信。countdown 一列走 `countdown_task.py` 自己的正则,**完全不受影响**。

**"full-ES" 与 "vanilla" 不是同一份代码。** 七月用 `es_train_fullparam.py`,
八月用 `es_train_axis.py --variant vanilla`。两者都是无轴探针的全参数 ES,
把它们当作"同一个方法"是一个**假设**,本文未验证。N 也不同(20 vs 16)。

**七月各臂均为单 seed。** 八月的双 seed 显示同方法跨 seed 的 ID 差可达 0.032,
与七月这些 −0.017 ~ −0.057 的差值同量级。**因此七月的单臂负号本身不构成证据**,
起作用的是方向的一致性(13 个数学数据集对比中 13 个为负)。

**countdown battery 是步数对齐(100 步),不是墙钟对齐**,其报告已注明这会低估 GRPO。

**三个 try 无基线这一点无法追溯补救。** 那些 arm 的权重多数未保存。

## 未解决

**为何 07-18 / 07-21 / 07-23 没做基线评测?** 台账与各 try 报告均无记录。
是有意省略(当时只关心臂间比较)还是疏漏,无从判断。

**countdown 的 ρ=0.51 是否来自连续奖励而非任务本身?** countdown 的奖励带接近度梯度,
数学是二元。无法区分"任务合适"与"奖励形状合适"——这两者在现有数据中完全共线。
要分离,需在数学任务上用连续奖励(07-21 的 `continuous_reward.py` 已实现)复测 ρ。

**B 的作用未被独立验证。** 本文把 ρ≈0 归因于 B=8 的粒度,依据是 07-28 overnight 测到
B=200 可把 ρ 拉到 0.31–0.46。但那是在不同配置下测的,未在本文涉及的任何 regime 中重复。
