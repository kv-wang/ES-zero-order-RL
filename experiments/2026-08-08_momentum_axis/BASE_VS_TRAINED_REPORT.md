# 为什么 base 在 MATH-500 上优于所有训练后的模型 (2026-08-13)

**结论:这不是训练损坏了能力,而是从一个已优化的局部最优点做任何无方向移动的必然统计后果。
正确是窄靶、错误是宽靶——L5 上 base 答对的题被改错的概率 0.229,答错的题被改对的概率
只有 0.034,相差 6.8 倍。**

> **适用范围(务必先读)。** 基座 `Qwen2.5-Math-1.5B-Instruct` **本身就是用 GRPO 训练出来的**
> (72B 奖励模型 + 迭代 rejection sampling + GRPO,见下文"基座并非中性起点")。
> 因此本文结论限定为:**在一个已被 GRPO 优化过的数学专家模型上,用弱奖励信号做同分布训练,
> 期望收益为负**。不可外推为"训练一般会损害模型"。普适性需在未经 RL 的基座上复现。

## 问题

统一评测表显示 base(MATH-500 L3-5 = 0.6452)高于全部四种训练方法(0.6037–0.6221),
且高于 GRPO(0.6037)。ID 与训练同分布,不是泛化问题。为什么?

## 设置

逐题配对分析,数据来自 `*_finaleval__math500_perq.jsonl`(字段 `gold` / `correct` /
`extracted` / `extracted_str` / `used_boxed` / `level`,n=300)。

对照 7 个训练臂:vanilla / baseaxis / momentum 各 2 seed + GRPO 1 次。全部与 base
逐行对齐(已断言 `gold` 相同),同一评测路径:贪心、cap 300、max_tokens 2048、fp16、
修复后的括号计数抽取器。

## 排除的解释

**抽取/格式** —— 不是原因。

| arm | acc | extract 率 | used_boxed 率 |
|---|---:|---:|---:|
| base | 0.7033 | 0.997 | 0.993 |
| grpo | 0.6700 | 0.997 | 0.997 |
| vanilla | 0.6700 | 0.993 | 0.987 |
| baseaxis | 0.6733 | 0.993 | 0.987 |
| momentum | 0.6733 | 0.990 | 0.987 |

各臂仍正常输出 `\boxed{}`,与 base 无差异。

**系统性能力损伤** —— 不是。各臂丢的**不是同一批题**:两两 Jaccard 仅 0.17–0.40,
四臂全丢的只有 3 题,而至少一臂丢的有 35 题。若训练破坏了某种能力,应当丢同一批。

**方法特异性** —— 不是。GRPO 净 −10 落在 ES 各臂(−6 ~ −13)区间内。

## 效应是真实且方向一致的

| 对比 | 净变化 |
|---|---|
| base → 7 个训练臂 | **−6, −9, −9, −10, −11, −13, −10(全部为负)** |
| 同方法不同 seed | +4, −4, −2 |
| 不同方法同 seed | +1, +1, 0 |

两组对照说明 churn(23–36 题)是本评测的噪声底,且方法间、seed 间**无方向性**。
方向性只存在于"训练 vs 未训练"这一条轴。七臂全负,符号检验双侧 **p = 0.016**。
(单臂 z 为 −1.28 ~ −2.98,均不过六重比较的 Bonferroni 阈值 2.64;一致性才是证据。)

## 机制第一层:边界效应决定**哪些题**翻转

| level | n | base_acc | a(1−a) | 实测 churn/题 |
|---|---:|---:|---:|---:|
| L1 | 27 | 0.852 | 0.126 | 0.011 |
| L2 | 56 | 0.857 | 0.122 | 0.046 |
| L3 | 64 | 0.797 | 0.162 | 0.038 |
| L4 | 81 | 0.630 | 0.233 | 0.074 |
| L5 | 72 | 0.528 | 0.249 | 0.137 |

**corr(a(1−a), churn 率) = +0.871。** L5 的 base 正确率 0.528 最接近抛硬币,
因而最容易被扰动翻转。这解释了 L5 占失分 56–71%(而它只占题目 24%)。

## 机制第二层:翻转严重**单向**,这才是根因

纯边界效应预测翻转对称。实测不是:

| level | base_acc | 丢 | 得 | 丢:得 | 二项 p |
|---|---:|---:|---:|---:|---:|
| L1 | 0.852 | 1 | 1 | 1.0 | 1 |
| L2 | 0.857 | 16 | 2 | 8.0 | 0.0013 |
| L3 | 0.797 | 7 | 10 | 0.7 | 0.63 |
| L4 | 0.630 | 23 | 19 | 1.2 | 0.64 |
| **L5** | **0.528** | **61** | **8** | **7.6** | **3.2e-11** |
| 全部 | | 108 | 40 | 2.7 | 2.1e-08 |

条件翻转概率把机制说透:

```
L5:  base 答对 → 被改错   0.229
     base 答错 → 被改对   0.034        相差 6.8 倍
L4:  0.064  vs  0.090                  相差 0.7 倍(无不对称)
```

**解释。** Qwen2.5-Math-1.5B-**Instruct** 已被重度数学后训练,处于局部最优。
它在 L5 上答对的题是**勉强答对**,依赖一条精确的推理路径,扰动容易让它偏离;
答错的题是**稳健地错**,通往错误的路很多,扰动几乎不可能恰好推到唯一正确的那条。
所以任何无方向的参数移动都以约 7:1 把 L5 的答案从对推到错。

**关键佐证:GRPO 的 KL 是 −2.1e-7,比 ES 小四个数量级,净变化却相同。**
位移大小与损伤程度无关——窄靶一旦离开就掉下去,离开多远不重要。这也解释了此前
测到的反直觉结果 corr(KL, ID) = +0.53(n=6)。

## 与"GRPO 训练奖励涨了 10 个点"不矛盾

GRPO 训练奖励 0.373→0.468、熵 0.147→0.115。但训练在 **温度 1.0** 下采样,
评测是**贪心**。收紧分布可以提高期望奖励,同时移动分布的众数——而贪心取的正是众数。
此外训练时 44–56% 的回答被 512 token 截断,奖励信号里含"写短一点"的成分,
而评测放宽到 2048,该压力不存在。

## 基座并非中性起点 —— 结论的适用范围因此收窄 (2026-08-13 补)

查阅 [Qwen2.5-Math 技术报告 (arXiv:2409.12122)](https://arxiv.org/abs/2409.12122) 与
[官方博客](https://qwenlm.github.io/blog/qwen2.5-math/) 后发现,`Qwen2.5-Math-1.5B-Instruct`
的后训练流程是:

1. 预训练 `Qwen Math Corpus v2`,>1T token,含 72B-Instruct 合成的数学数据
2. 训出 `Qwen2.5-Math-RM-72B` 奖励模型,用它做 Rejection Sampling 构造 SFT 数据,
   并与 SFT 交替迭代
3. **在最终 SFT 模型上用 GRPO 做强化学习**

**即本实验的基座已经被 GRPO 在数学任务上专门优化过。** 这对报告结论有两点影响:

**一、"窄靶"机制的普适性未经检验。** 本报告观测到的不对称(L5 上 0.229 vs 0.034)
是在一个**已被同类算法推到局部最优**的模型上测得的。它可能是任何充分优化模型的通性,
也可能特定于"被 GRPO 优化过、再被 GRPO/ES 推动"这一情形。**当前数据无法区分**。
要证实普适性,需在一个未经 RL 的基座(例如 `Qwen2.5-Math-1.5B` 非 Instruct 版)上复现。

**二、GRPO 那一臂的解释力被进一步削弱。** 我们用二元 `\boxed{}` 正确性 + 2000 道题,
去改进一个用 72B 奖励模型 + 迭代 rejection sampling 训出来的结果。GRPO 臂的 ID 退化
更可能反映"弱奖励信号覆盖掉强奖励信号"的结果,而非 GRPO 方法本身的性质。

**三、训练集去污染不一致。** 博客提到 Qwen 团队注意到 MATH 训练集中"有相当比例的题目"
在结构上与测试集相似,并**排除了这类污染样本**。而本实验的 2000 道题是从完整 MATH L3-5
train split 随机抽取,**未做同样的去污染**。这会让训练奖励更容易上升、测试准确率更难上升,
是 GRPO 臂"训练奖励 +0.094 / ID −0.042"这一组合的又一个候选解释。

**因此本报告的结论应表述为:在一个已被 GRPO 优化过的数学专家模型上,用弱奖励信号做
同分布训练,期望收益为负,机制是正确答案处于窄靶。而非"训练一般会损害模型"。**

## 未解决

**L2 的 8:1(丢 16 得 2,p=0.0013)没有解释。** base_acc 0.857 处按边界效应不该有
大量翻转。n=56 偏小,但值得单独查。

**GRPO 的 FSDP→HF 合并往返未隔离。** `config.json` 的 `torch_dtype` 从 bfloat16 变为
None,舍入路径不同。需把 base 也走一遍合并再评测才能定量。不过 ES 不经过合并却呈现
同样的模式,故此项对总结论已不关键。

**单 seed(GRPO)、单数据集(MATH-500 300 题)。** 其余五套 OOD 未做同样的逐题分解;
OOD 上四种方法反而略高于 base(+0.004~+0.013),与 ID 方向相反,尚未解释。

**未验证的推论。** "窄靶"机制预测:base 正确率越接近 0.5、不对称越强。当前只有
L5(0.528,7.6:1)与 L4(0.630,1.2:1)两点,不足以拟合。需要更多 level 或
更多数据集才能证实。

## 对整个研究计划的含义

若该机制成立,则**在一个已充分后训练的模型上,用弱信号方法(此 regime 下 ES 的
split-half ρ ≈ 0)做同分布训练,期望收益为负**。这与台账中两个 P0 一致:
应当搬到 base 能力低、有真实提升空间的 regime(countdown,base 0.08),
而不是在 base 已达 0.65 的 MATH L3-5 上继续比较。
