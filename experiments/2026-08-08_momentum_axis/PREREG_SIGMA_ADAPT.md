用户提出的想法:**ES 的"梯度"越大,扰动的 σ 越大**,同时保持 α 不变。
本文件在看到任何结果之前冻结判读标准。

运行:tmux 会话 `sig`,`axis_probe/run_sigma_adapt.sh`,4 臂约 4.9h。

## 用什么当"梯度范数"

三个候选,选了第三个:

| 候选 | 为何不用 / 用 |
|---|---|
| `‖Δ‖`(update_l2) | **不可用**。z-score 把它钉成常数 `α√(d/N)`,实测变异系数 0.0001(vanilla 195 步) |
| `Σ_k a_k(z₊−z₋)`(探针系数) | **不可用**。vanilla 里不存在;且 52–65% 的步恰好为 0 |
| **`fitness_std`** | **采用**。它在数学上就是 ES 梯度范数 |

因为 `ĝ = (1/(Nσ))Σ(f_i−f̄)ε_i`,高维近正交下 `‖ĝ‖ ≈ √(d/N)·std(f)/σ`,
所以 `fitness_std` 与 `‖ĝ‖` 只差一个已知常数。它对 vanilla 同样定义,
实测变异系数 0.59–0.64,是三者中唯一既有信息又普适的。

## 控制律

```
σ_t = σ₀ · clip( (fs_ema / fs_ref)^gain , 1/clip , clip )
```

- `fs_ref`:前 `--sigma_adapt_warmup=10` 步 fitness_std 的均值,标定一次后冻结
- `fs_ema`:fitness_std 的 EMA(β=0.9),平滑约 17% 的零更新步
- **因果**:σ_t 只用 t 步之前的 fitness_std
- 默认 gain=1.0、clip=2.0,即 σ ∈ [σ₀/2, 2σ₀]
- **α 完全不动**

## 预注册的判读顺序

**第一步永远先看 `sigma_ratio_min/mean/max`,再看准确率。** 三种情形:

1. **贴下界(mean ≈ 0.5)** → 反馈跑反了。零信号压低 σ、σ 变小使打平更频繁、
   进而更多零信号——自反馈。这是**机制层面的否定**,与准确率无关,
   不应通过调 gain/clip"抢救"。
2. **贴上界(mean ≈ 2.0)** → gain 相对 clip 太大,控制律饱和,等于换了个固定 σ=2σ₀。
   这是**标定问题**,可在下一轮调 gain。
3. **在带内移动** → 才算真正测到了这个想法,此时才看下一层。
4. **σ 变了但打平率不动**(补充于 21:5x,仍在数据产出之前)→ 说明 σ 在
   [0.5σ₀, 2σ₀] 这个范围内**跨不过奖励的离散档位**,clip 带太窄。
   这是**量程问题**,不是想法的否定;下一轮应放宽 clip 或直接做 σ dose-response。

新增情形 4 的理由见下文"更正":σ 对更新的一阶效应为零,它唯一的主导作用路径就是
改变奖励量化下的可分辨性。所以**打平率是比准确率更靠前的判读指标**——
若打平率不动,准确率不可能动,后者的 null 不携带信息。

**GO**:`sigma_ratio` 在带内移动,**且**打平率相对固定 σ 显著下降,
**且**配对 McNemar 在 ID 或 OOD 上给出 |z|≥1.96(六重比较需过 Bonferroni)。

**NEGATIVE(照实报告)**:情形 1(自反馈跑反),或情形 3 下打平率下降却无准确率收益。

**INCONCLUSIVE**:情形 2 或 4——控制律没被真正测试,不得记为对想法的否定。

## 已知的、本实验无法回答的问题

**~~α 未被隔离~~ —— 更正 (2026-08-10 21:5x,仍在数据产出之前)。**
本文件初版写道"有效学习率 `α·σ_t` 随 σ 同比变化,σ 减半步长也减半",
因而两臂的差异分不开半径与步长。**该判断是错的**,现更正如下。

σ **根本不出现在更新式里**。代码:`gauss_coeffs = (α/N)·z`,提交时
`delta.add_(noise, alpha=c)` 用的是原始 `ε` 而非 `σε`。所以

```
‖Δ‖ ≈ α·√(d/N)      与 σ 无关
```

更根本的原因是 z-score:小 σ 的线性区里 `f_i − f̄ ≈ σ⟨g, ε_i⟩`、
`std(f) ≈ σ‖g‖`,于是

```
z_i = (f_i − f̄)/std(f) ≈ ⟨g, ε_i⟩ / ‖g‖
```

**σ 在 z 里被精确约掉。** 即线性区内改 σ 对更新连一阶影响都没有。

**结论反而对本实验有利**:两臂的步长本来就相同,唯一变量就是探针半径,
不需要额外的补偿臂。`effective_lr` 字段仍然落盘,但它现在只是
`α·σ_t` 这个派生量,不代表真实步长。

**那么 σ 改变什么。** 全在二阶,而本设置下只有一条路径是主导的:
**奖励量化**。B=8 时奖励仅 9 个取值,当前打平率 64–75%。σ 越大成员被推得越远、
`f_i` 越容易落进不同档位 → 打平率下降;σ 越小越多成员挤在同一档 → `z` 全零、零更新。
次要路径是非线性偏差(σ 超出线性区后有限差分测的是割线)。

**因此判读的核心指标是打平率,不是准确率**——见上文判读顺序的情形 4。

**方向存疑。** ES 里 σ 是探针距离,失效模式两头堵:太小则奖励差落进 B=8 的量化底
(当前打平率 64–75%),太大则测跨越非线性区的割线而有偏。
`fitness_std` 大意味着当前 σ 已足够撬动奖励,此时放大 σ 反而加剧偏差;
`fitness_std`=0 才是探针太钝、该放大。**按机制推测方向应当相反。**
本轮即是对这一推测的直接检验。

**ρ≈0 的背景。** 2026-08-10 标准轮首次测得本 regime 的 split-half ρ 中位数为 0,
成员排名是纯抽样噪声。若如此,`fitness_std` 的波动大概率也主要是噪声,
控制器可能只是在追噪声——这会表现为 `sigma_ratio` 高频抖动但无系统趋势。

**双 seed。** 未满足 3-seed 规则,准确率维度的差异大概率落在噪声内。
